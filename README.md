
# Receivables Automation Tool

An Excel VBA project designed to automate accounts receivable workflows using macros, UserForms, and validation systems.

## Features
- Add and manage customer receivables
- Automatically calculate balances and due dates
- VBA UserForms for cleaner data entry
- Validation to reduce incorrect input
- Event-driven automation using worksheet events
- Organized multi-module VBA structure

## Technologies Used
- Microsoft Excel
- VBA (Visual Basic for Applications)
- Excel Macros
- UserForms

## Project Structure
- `Modules/` → VBA logic modules
- `Forms/` → UserForm code
- `Workbook_Events.txt` → Workbook event automation examples
